# AGENTS.md

Instructions for anyone, person or AI agent, who changes a VisiCore repository. A repository's own `AGENTS.md`
adds to these.

## Pull requests

Write every pull request description from the
[organization pull request template](https://github.com/VisiCore/.github/blob/main/.github/pull_request_template.md),
or from the repository's own `.github/pull_request_template.md` when it has one. Fill in each section that applies
and delete the rest. GitHub fills in the template for a pull request opened in the browser. With `gh pr create`,
pass the finished text with `--body-file`.
